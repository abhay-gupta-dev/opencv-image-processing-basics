# OpenCV Image Processing Basics

A lightweight Python project demonstrating foundational computer vision and image processing techniques using the **OpenCV** library (`cv2`). 

This project is great for beginners looking to understand how to load images, manipulate pixel data, convert color spaces, and extract edges using gradient algorithms.

---

## Features
* **Image Loading & Properties:** Read images and inspect attributes like shape, data type, size, and individual pixel values.
* **Color Space Conversion:** Convert standard BGR images to Grayscale.
* **Edge Detection:** Implement **Canny Edge Detection** to highlight structural outlines in images.
* **Display & Save:** Preview processed images in windows and save output files locally.
